# 极简输入示例

这些示例用于验证 Skill 的核心行为：**用户不需要学习格式。**

## 示例 1：只有主体

输入：

```text
一位成年女性，黑色长直发，银色亮片小挎包。
```

预期：直接生成 1 条完整固定机位提示词；默认采用单元门禁摄像头，不追问机位、时间、动作或画质。

## 示例 2：主体 + 场景词

输入：

```text
一位成年女性，黑长发，电梯。
```

预期：自动选择电梯角落鱼眼监控。

## 示例 3：主体 + 天气词

输入：

```text
成年女性，银色小包，雨夜门口。
```

预期：自动选择门禁摄像头，并加入湿地反光、雨丝、镜头水点和夜间低饱和画质。

## 示例 4：宠物 + 红外

输入：

```text
一只白胸折耳猫，深夜红外。
```

预期：自动使用适合宠物或户外的低机位/红外固定摄像头，依赖白胸、折耳等形状锚点保持识别。

## 示例 5：自然语言 series=9

输入：

```text
一位成年女性，黑色长直发，银色小包，同一门口连续九天。
```

预期：自动识别为 series=9。同一机位、同一固定场景，连续 9 天，最后一天可平静直视设备。

## 示例 6：自然语言 n=10

输入：

```text
一位成年女性，黑长发，做十种不同摄像头视角。
```

预期：自动识别为 n=10，输出十种明显不同的固定机器摄像头视角。

## 示例 7：极短输入

输入：

```text
成年女性，白裙。
```

预期：仍然直接工作。Skill 自动补足虚构成年人物、默认门禁机位、自然日常动作、设备画质、OSD 与 4:3 比例。

## 行为验收

以上输入均不得回复：

- “请提供主体”
- “请指定机位”
- “请选择模式”
- “请补充时间/天气”

除非用户明确要求修改，否则缺失信息一律自动补全。
