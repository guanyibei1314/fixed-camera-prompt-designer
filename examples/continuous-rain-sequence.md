# 连续截图示例：雨夜回家 6 帧

目标：验证 sequence 模式是否真的做到“同一人物 + 同一服装 + 同一道具 + 同一背景 + 同一机位 + 严格递增时间 + 单向动作推进”。

## 输入

```text
同一个人，雨夜回家，给我6张连续截图。
```

## Continuity Lock

以下内容 6 帧都不能改变：

- 同一个主体
- 黑色中长直发，齐刘海
- 米白色连帽防水外套
- 深灰色百褶裙
- 白色中筒袜
- 浅粉色运动鞋
- 浅粉色双肩包
- 包左下侧挂一只白色毛绒兔子挂件
- 同一把透明长伞，银色伞骨，白色弯柄
- 同一台 `UNIT 3  ENTRANCE  CAM 01`
- 摄像头固定在门框左上方高位，向下斜俯视，4:3，轻度桶形畸变

固定背景：

- 右侧玻璃单元门
- 门左侧银灰色门禁面板
- 门禁面板上方黑色纵向信箱
- 三层灰色石材台阶
- 中右侧矩形花坛和深绿色灌木
- 左侧路边同一辆白色轿车
- 远处同一辆深色轿车
- 左后方同一盏暖黄色路灯
- 湿润石材地面与相同反光位置

天气锁定：中雨持续。每帧都必须能看到雨丝、伞面雨滴、湿地反光、水痕，以及路灯照亮的雨线。只加轻微传感器噪点和压缩感，不允许噪点遮住雨和人物。

## Frame 1/6

主体刚进入摄像头左下方视野，撑着透明伞沿湿润步道向台阶走来。人物距离门最远，包和兔子挂件完整可见。雨丝在路灯下明显，伞面布满雨滴。

左上 OSD：`UNIT 3  ENTRANCE  CAM 01`
右下时间：`2025-08-12 20:41:07`

## Frame 2/6

同一人物、同一服装、同一双肩包、同一兔子挂件、同一透明伞、同一机位与背景。人物已经踏上第一层台阶，左脚抬起向上，动作正在进行。人物只能比 Frame 1 更靠近门，不能退回。

右下时间：`2025-08-12 20:41:12`

## Frame 3/6

人物走到台阶顶部靠近门前区域，开始把透明伞略微收拢，但仍保持撑开状态以挡雨。右手靠近门禁方向，双肩包仍在同一位置。雨强与前两帧一致。

右下时间：`2025-08-12 20:41:17`

## Frame 4/6

人物已经站到银灰色门禁面板前，用右手按下门禁键，左手仍握同一把透明伞。服装、鞋袜、发型、背包、兔子挂件都必须与 Frame 1 完全一致。

右下时间：`2025-08-12 20:41:22`

## Frame 5/6

人物按完门禁后原地等待，右手已经放下，身体朝玻璃门方向。透明伞仍撑着，雨丝持续可见。她的位置只能与 Frame 4 基本相同或略向门靠近。

右下时间：`2025-08-12 20:41:28`

## Frame 6/6

玻璃门已经开启一条缝，人物向门内迈出一步，仍然是同一人物、同一服装、同一双肩包、同一兔子挂件和同一透明伞。动作是整个 sequence 的最终推进状态，不回退到台阶或街道。

右下时间：`2025-08-12 20:41:35`

## 验收标准

- 6 张里主体看起来必须是同一个人。
- 发型、上衣、裙子、袜子、鞋、背包、兔子挂件、透明伞完全一致。
- 摄像机位置和画面裁切不能变化。
- 门、门禁、信箱、台阶、花坛、车辆、路灯的位置关系不能变化。
- 时间必须严格按 07 → 12 → 17 → 22 → 28 → 35 秒递增。
- 动作必须按“走近 → 上台阶 → 到门前 → 按门禁 → 等待 → 进门”单向推进。
- 每张都必须明显看出正在下雨，而不是仅仅地面湿。
- 监控噪点只能轻度存在，不能影响雨丝和主体辨认。
