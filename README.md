# Fixed Camera Prompt Designer

一个把**一句自然语言短句**自动扩展为固定机位机器摄像头 / CCTV / 门禁 / 鱼眼 / 红外夜视风格图片生成提示词的 Skill。

## v1.3.0：新增连续截图模式

现在除了单张、`n=10`、`series=9`，还支持真正的 **sequence 连续截图**。

例如直接输入：

```text
同一个人，雨夜回家，给我6张连续截图。
```

Skill 会自动锁定：

- 同一个人物
- 同一发型、刘海、衣服、鞋袜
- 同一个包/背包与挂件
- 同一把伞
- 同一台摄像头与同一构图
- 同一扇门、台阶、信箱、花坛、车辆、路灯
- 严格递增的时间戳
- 单向推进的动作过程

它不再把“连续截图”做成几张相似主题的独立图片。

## 连续截图和 series=9 的区别

`sequence`：同一事件，通常几秒到几十秒。人物衣服、道具、天气、背景和机位都必须锁死。

`series=9`：同一固定机位跨 9 天记录。背景与主体核心识别锚点保持一致，但服装、天气和日常事件可以变化。

`n=10`：同一主体做 10 种不同机器摄像头视角，重点是多样性，而不是连续性。

## 雨天表现升级

如果用户写“下雨 / 雨夜”，不能只做湿地面或拿伞。每帧至少要有 4 类明显降雨证据，例如：

- 空中可见雨丝
- 伞面雨滴或水流
- 湿地高光反射 / 小水洼
- 台阶与路面水痕
- 路灯照亮的雨线
- 头发、袖口、鞋边轻微湿润
- 玻璃或镜头少量水滴

## 监控画质升级

默认改成**轻度监控缺陷**：轻微传感器噪点、压缩块、暗角、桶形畸变和高光溢出。

原则：**先看清人物、动作、天气和环境，再感觉到这是监控。** 不再让大颗粒噪点盖住雨丝和主体。

## 时间轴规则

连续截图必须先规划完整时间线，再逐帧生成。时间戳只能递增，不能倒序或重复。

6 帧默认示例：

```text
20:41:07
20:41:12
20:41:17
20:41:22
20:41:28
20:41:35
```

```text
一位成年女性，黑色长直发，银色亮片小挎包。
```

```text
成年女性，银色小包，雨夜门口。
```

```text
黑长发成年女性，电梯，刚下班。
```

```text
一只白胸折耳猫，深夜红外。
```

```text
一位成年女性，黑长发，同一门口连续九天。
```

```text
一位成年女性，黑长发，做十种不同摄像头视角。
```
