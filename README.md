# Fixed Camera Prompt Designer

一个把主体描述转换为固定机位机器摄像头 / CCTV / 门禁 / 鱼眼 / 红外夜视风格图片生成提示词的 Skill。

## 主要能力

- 单张固定机位监控风格提示词
- `n=10`：同一主体，10 种明显不同的机器摄像头视角
- `series=9`：同一台摄像头、同一地点、连续 9 天
- 主体锚点保持：发型、轮廓、包、挂件、宠物形状特征等
- 精确 OSD 设备文字与时间戳
- 低保真录像质感：桶形畸变、压缩块、噪点、轻微失焦、红外灰阶

## 文件

- `SKILL.md`：完整 Skill 规则
- `skill.json`：元数据
- `examples/series-9-unit-entrance.md`：单元门禁连续 9 天完整示例

## 示例输入

```text
主体：虚构成年女性，黑色长直发过肩，身材纤细，银色亮片链条小挎包，包上挂毛绒兔子挂件。
模式：series=9
机位：单元门禁摄像头
衣着档位：清凉
```

核心视觉原则：**镜头后面没有人，机器一直在看。**

所有生成内容按 `SKILL.md` 中的安全边界执行：虚构摆拍、成年人物、非私密空间、非真实监控泄露素材。
