# Fixed Camera Prompt Designer

一个把**极简自然语言**自动扩展成固定机位机器摄像头 / CCTV / 门禁 / 鱼眼 / 红外夜视风格图片生成提示词的 Skill。

## 最简单的用法

不需要写参数，不需要写 `主体:`、`模式:`、`机位:`。

直接输入：

```text
一位成年女性，黑色长直发，银色亮片小挎包。
```

Skill 会自动补全：

- 固定机位摄像头类型
- 场景与时间
- 日常动作
- 主体在画面中的位置
- 桶形畸变 / 鱼眼
- 低清压缩块与传感器噪点
- OSD 设备文字和时间戳
- 4:3 比例

默认会生成单元门禁摄像头风格的 1 条完整提示词。

## 自然语言也能覆盖默认值

```text
一位成年女性，黑长发，雨夜门禁。
```

```text
黑长发成年女性，电梯。
```

```text
一只白胸折耳猫，深夜红外。
```

```text
一位成年女性，银色小包，连续九天。
```

```text
成年女性，黑长发，十种摄像头。
```

Skill 会自动识别场景、天气、机位和 `series=9` / `n=10`，无需结构化语法。

## 主要能力

- 零配置：一句主体描述直接生成
- 单张固定机位监控风格提示词
- `n=10`：同一主体，10 种明显不同的机器摄像头视角
- `series=9`：同一台摄像头、同一地点、连续 9 天
- 主体锚点保持：发型、轮廓、包、挂件、宠物形状特征等
- 精确 OSD 设备文字与时间戳
- 低保真录像质感：桶形畸变、压缩块、噪点、轻微失焦、红外灰阶

## 文件

- `SKILL.md`：完整 Skill 规则
- `skill.json`：元数据
- `examples/minimal-inputs.md`：极简自然语言输入示例
- `examples/series-9-unit-entrance.md`：单元门禁连续 9 天完整示例

核心视觉原则：**镜头后面没有人，机器一直在看。**

所有生成内容按 `SKILL.md` 中的边界执行：虚构摆拍、明确成年人物、非私密空间、非真实监控泄露素材。
