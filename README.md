# Fixed Camera Prompt Designer

一个把**一句自然语言短句**自动扩展为固定机位机器摄像头 / CCTV / 门禁 / 鱼眼 / 红外夜视风格图片生成提示词的 Skill。

## 升级后的核心能力

- **极简输入直接生效**：用户只写 `一位成年女性，黑长发，银色小包。` 也直接出完整提示词
- **一句话语义映射**：自动从短句中推断机位、时间、天气、动作、氛围和 OSD
- **默认不反问**：缺失信息自动补全，不要求用户学习 `主体:`、`模式:` 之类格式
- **单张 / `n=10` / `series=9`** 都支持
- **主体锚点保持**：发型、轮廓、包、挂件、宠物形状特征等
- **低保真录像质感**：桶形畸变、压缩块、噪点、轻微失焦、红外灰阶

## 现在推荐的输入方式

直接像说话一样写：

```text
一位成年女性，黑色长直发，银色亮片小挎包。
```

```text
成年女性，银色小包，雨夜门口。
```

```text
成年女性，深夜回家，有点疲惫。
```

```text
一只白胸折耳猫，深夜红外。
```

```text
一位成年女性，黑长发，同一门口连续九天。
```

```text
一位成年女性，黑长发，做十种不同摄像头视角。
```

## 语义映射示例

- `门口 / 回家 / 楼下` → 单元门禁摄像头
- `电梯` → 电梯鱼眼监控
- `雨夜` → 湿地反光 + 雨丝 + 镜头水点
- `深夜` → 夜间低照度或红外灰阶
- `刚下班 / 有点累` → 扶门、微弯腰、动作停在中间状态
- `刚买完东西` → 购物袋 / 便利店袋 / 纸箱等道具

核心视觉原则：**镜头后面没有人，机器一直在看。**

所有生成内容按 `SKILL.md` 中的安全边界执行：虚构摆拍、成年人物、非私密空间、非真实监控泄露素材。
